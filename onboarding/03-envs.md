# Passo 3 — Variáveis na Vercel

Crie um projeto na Vercel com **Root Directory** = `app`.

Grave só na Vercel, encriptado. Não cole valor neste repositório.

| Variável | Para quê |
|---|---|
| `EKYTE_MCP_TOKEN` | MCP oficial do Ekyte |
| `MCP_COCKPIT_JWT` | FLOW / Cockpit |
| `MCP_GATEWAY_TOKEN` | Gateway do Cockpit |
| `APP_PASSWORD` | Senha da Central |

O detalhe de cada uma está em [docs/adaptar.md](../docs/adaptar.md).
