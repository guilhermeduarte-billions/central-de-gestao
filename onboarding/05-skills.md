# Passo 5 — Adaptar as skills

As três skills estão em `skills/`. O aviso no topo de cada uma vale: troque workspace, projeto, tipo, fases e executores antes de usar.

| Skill | Quando |
|---|---|
| `skills/ekyte-acao-gerencial` | Antecipação, retenção e apoio da gerência |
| `skills/ekyte-acao-operacional` | Pedido seu para o time de operações |
| `skills/ekyte-expansao` | Oportunidade de expansão |

`ekyte-task` não faz parte deste método.

Na operacional, o ponto que mais quebra é o fluxo de validação: o tipo padrão aponta outra pessoa. A skill do Guilherme sobrescreve para ele. Você sobrescreve para você.

Quando usar cada uma: [docs/skills.md](../docs/skills.md).
