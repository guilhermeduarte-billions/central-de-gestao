# Onboarding

O clone não executa nada sozinho. O primeiro comando, dentro da pasta do repositório, é:

```bash
./onboarding/iniciar.sh
```

O script mostra um passo, espera você concluir e só então avança. Cada passo é uma troca para o seu caso. Os IDs que aparecem são o exemplo Billions do Guilherme Duarte.

| Passo | Arquivo | O que você faz |
|---|---|---|
| 1 | [01-mcp.md](01-mcp.md) | Ligar o MCP oficial do Ekyte |
| 2 | [02-glossario.md](02-glossario.md) | Ler o que é antecipação, retenção e expansão |
| 3 | [03-envs.md](03-envs.md) | Criar as variáveis na Vercel, sem commitar valor |
| 4 | [04-escopos.md](04-escopos.md) | Trocar workspace, projetos e pessoas |
| 5 | [05-skills.md](05-skills.md) | Adaptar as três skills ao seu time |
| 6 | [06-titulo-e-semana.md](06-titulo-e-semana.md) | Título com coordenador e ticker, etiqueta `SEMANA XX` |
| 7 | [07-senha-e-daily.md](07-senha-e-daily.md) | Senha da Central e a cola no Docs da daily |
